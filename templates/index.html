Mathematical Discussion

The Composite Trapezoidal Rule is a numerical integration method used to approximate the definite integral of a function. It divides the integration interval into multiple subintervals and applies the trapezoidal rule to each subinterval.

Formula

For a function \(f(x)\) over the interval \([a, b]\) divided into \(n\) subintervals:

$$\int_a^b f(x)\,dx \approx \frac{h}{2}\left[f(x_0) + 2\sum_{i=1}^{n-1}f(x_i) + f(x_n)\right]$$

where:

  • \(h = \frac{b-a}{n}\) is the step size
  • \(x_i = a + ih\) for \(i = 0, 1, 2, ..., n\)

Algorithm Steps

  1. Step 1: Calculate the step size: \(h = \frac{b-a}{n}\)
  2. Step 2: Evaluate \(f(a)\) and \(f(b)\)
  3. Step 3: Calculate the sum of interior points: \(\sum_{i=1}^{n-1}f(x_i)\)
  4. Step 4: Apply the formula to get the approximation

Error Analysis

The error in the Composite Trapezoidal Rule is given by:

$$E = -\frac{(b-a)^3}{12n^2}f''(\xi)$$

where \(\xi\) is some point in \([a, b]\). The error decreases as \(O(h^2)\) or \(O(1/n^2)\).

Worked Examples

Example 1: Polynomial Function

Beginner
Problem: Approximate \(\int_0^2 x^2\,dx\) using the Composite Trapezoidal Rule with \(n=4\) subintervals.

Solution:

Step 1: Calculate step size
$$h = \frac{b-a}{n} = \frac{2-0}{4} = 0.5$$
Step 2: Calculate the x-values
$$x_0 = 0, \quad x_1 = 0.5, \quad x_2 = 1.0, \quad x_3 = 1.5, \quad x_4 = 2.0$$
Step 3: Evaluate the function at each point
$$\begin{align} f(x_0) &= 0^2 = 0\\ f(x_1) &= 0.5^2 = 0.25\\ f(x_2) &= 1.0^2 = 1.0\\ f(x_3) &= 1.5^2 = 2.25\\ f(x_4) &= 2.0^2 = 4.0 \end{align}$$
Step 4: Apply the formula
$$\begin{align} I &\approx \frac{h}{2}\left[f(x_0) + 2\sum_{i=1}^{3}f(x_i) + f(x_4)\right]\\ &= \frac{0.5}{2}\left[0 + 2(0.25 + 1.0 + 2.25) + 4.0\right]\\ &= 0.25\left[0 + 2(3.5) + 4.0\right]\\ &= 0.25\left[11.0\right]\\ &= 2.75 \end{align}$$

Exact value: \(\int_0^2 x^2\,dx = \left[\frac{x^3}{3}\right]_0^2 = \frac{8}{3} \approx 2.6667\)

Error: \(|2.75 - 2.6667| = 0.0833\)

Example 2: Exponential Function

Intermediate
Problem: Approximate \(\int_0^1 e^x\,dx\) using the Composite Trapezoidal Rule with \(n=5\) subintervals.

Solution:

Step 1: Calculate step size
$$h = \frac{b-a}{n} = \frac{1-0}{5} = 0.2$$
Step 2: Calculate the x-values
$$x_0 = 0, \quad x_1 = 0.2, \quad x_2 = 0.4, \quad x_3 = 0.6, \quad x_4 = 0.8, \quad x_5 = 1.0$$
Step 3: Evaluate the function at each point
$$\begin{align} f(x_0) &= e^0 = 1.0000\\ f(x_1) &= e^{0.2} \approx 1.2214\\ f(x_2) &= e^{0.4} \approx 1.4918\\ f(x_3) &= e^{0.6} \approx 1.8221\\ f(x_4) &= e^{0.8} \approx 2.2255\\ f(x_5) &= e^{1.0} \approx 2.7183 \end{align}$$
Step 4: Calculate sum of interior points
$$\sum_{i=1}^{4}f(x_i) = 1.2214 + 1.4918 + 1.8221 + 2.2255 = 6.7608$$
Step 5: Apply the formula
$$\begin{align} I &\approx \frac{h}{2}\left[f(x_0) + 2\sum_{i=1}^{4}f(x_i) + f(x_5)\right]\\ &= \frac{0.2}{2}\left[1.0000 + 2(6.7608) + 2.7183\right]\\ &= 0.1\left[1.0000 + 13.5216 + 2.7183\right]\\ &= 0.1 \times 17.2399\\ &= 1.7240 \end{align}$$

Exact value: \(\int_0^1 e^x\,dx = \left[e^x\right]_0^1 = e - 1 \approx 1.7183\)

Error: \(|1.7240 - 1.7183| = 0.0057\)
